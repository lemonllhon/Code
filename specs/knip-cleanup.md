# Knip 剩余项审计与清理

本文记录首轮清理。后续对 54 个文件及其它告警的逐项处置、当前数量和验证结果见 [剩余告警核对](knip-remaining-audit.md)。

## 规则与边界

- 先识别真实入口再判定未使用：HTML 中的 module script、独立浏览器夹具、构建子进程、声明文件和架构契约示例均可能没有普通 import 消费者。
- Knip 告警必须结合全仓文本引用、导出引用、package scripts、打包配置和现有测试确认；不能仅凭一次零引用报告删除，也不以通配忽略规则掩盖未核对项。
- 删除确认没有调用方的代码或依赖；文件内仍有调用时只收窄多余导出。动态使用或公开契约有依据时保留，并让分析配置准确表达入口/运行环境。
- 不改变应用状态所有者、服务契约语义、命令 admission、远程恢复、持久化及用户数据；不恢复先前删除的模块，不覆盖无关本地改动。
- BigModel Coding Plan 与 Z.AI Coding Plan 的模板、Key、模型、网关及普通供应商能力保持原样，作为每批改动的回归边界。

## 分析入口

- 浏览器夹具的入口来自实际 HTML module script，不能把所有辅助文件都当入口；解析器仅处理仓库内本地文件，不执行 HTML，也不请求网络。
- Node 测试、构建脚本和架构契约按实际调用或约定纳入。浏览器运行时的 Vite 绝对 URL 不应被解释为磁盘绝对路径。
- 平台命令和 Electron 虚拟模块保留其运行环境语义；原生依赖须核对打包与跨平台装配，不能根据当前 Windows 上是否加载来决定删除。

## 本轮核对决策

- 当前侧栏由 `WorkspaceSidebar/UnifiedSidebarTree.tsx` 承载。旧分组列表中由 Knip 和全仓引用共同确认、没有外部消费者的闭合依赖组可以删除；动态缓存测试仍消费的 `useWorkspaceTaskLists` 及实际被复用的行/颜色组件保留。
- 文件内仍使用的声明只移除多余 `export`，不改变初始化或实现；包公开入口及推导出的跨文件返回类型保留。`GitPaneSection` 经公开 hook 返回值间接暴露，声明生成验证证明必须继续导出。
- 删除无调用方的旧 wrapper、状态/拖拽 helper 和单 Key 输入组件；真实供应商编辑器仍由现有多 Key 编辑链路提供。
- 继续清理无消费者的 `lib/workspacePurpose`、旧分组列表 `shared` barrel、`providers/api/index` 及仅经它暴露的旧 Key header helper、运行环境 `records` 类型别名。它们不是 package exports；公开 Node API 入口及实际使用的 API transport/JSON/请求头工具保留，运行环境 schema 继续唯一归 `@lcode/shared` 所有。
- 删除依赖前核对源码、组件库、构建别名和平台装配。补齐真实 import 所属 workspace 的直接依赖声明，使用锁文件内已有版本；冻结安装验证不得引入新的包版本。
- 侧栏回归需区分本轮清理与工作区其它行为改动：初始源码的侧栏场景通过；当前 `WorkspaceSidebarItem` 已另行调整为离线打开时进入项目准备/重连，旧场景仍要求“新建远程会话”禁用。本轮不修改该产品实现、不改旧断言，记录契约不一致的失败。

## 验收

1. 前后 Knip 报告可对照，清理结果不依赖跳过文件或批量 suppress。
2. 根 typecheck/lint 与架构检查通过；涉及 CLI 时运行 CLI typecheck/lint。
3. 对应行为测试及两个供应商的正式 Adapter、桌面/手机添加与 Key 保存回归通过。
4. 如仍有保留项或检查失败，记录真实原因，不能以告警减少代替功能验证。

## 2026-10-23 实施与验证记录

- 删除 29 个无消费者文件（旧分组列表及闭合依赖、废弃输入组件、wrapper/helper、非公开 barrel 与类型别名），收窄 111 个文件中的 164 项内部导出。实现和文件内初始化保留；包公开入口、推导返回类型、动态测试入口及跨平台装配保留。
- 移除 14 项依赖声明，补齐真实 import 的 workspace 直接归属；锁文件没有新增包版本，去掉 41 个不再需要的包记录。`pnpm install --lockfile-only --offline --frozen-lockfile --ignore-scripts` 通过。
- 清理涉及 `desktop`、`ui`、`services`、`web` 及 CLI 的依赖声明。受控源码集合相对开工快照净减 4239 行（含新增 Knip 配置和 HTML 入口发现/测试，不含 manifest、锁文件和文档）；保留其它本地改动。
- 本轮不引入可变业务状态和新写入路径，不改变事件顺序、owner/lease、桌面连续流或手机恢复协议。
